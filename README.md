# Brasa Trenta

## Sistema de Comandas — Em Construção

O **Brasa Trenta** é um sistema de comandas que está atualmente em desenvolvimento, criado com o objetivo de facilitar e organizar o processo de atendimento e preparo dos pedidos em um estabelecimento.

O sistema será responsável por **ler, registrar e interpretar o pedido realizado pelo cliente**, encaminhando automaticamente as informações para a **cozinha**, onde a equipe poderá visualizar e executar o pedido.

## Objetivo

O principal objetivo do projeto é desenvolver uma solução que torne o processo de pedidos mais rápido, organizado e eficiente, reduzindo possíveis erros na comunicação entre o atendimento e a cozinha.

## Funcionamento

O funcionamento previsto do sistema será:

1. O cliente realiza seu pedido.
2. O sistema realiza a leitura e o registro do pedido.
3. As informações do pedido são processadas.
4. O pedido é enviado automaticamente para a cozinha.
5. A cozinha recebe os itens que precisam ser preparados.
6. A equipe da cozinha executa o pedido.
7. O status do pedido pode ser atualizado conforme o andamento.

## Funcionalidades
